# Démos Presales

Dépôt de pages de démonstration publiées sur GitHub Pages (`https://diabolocom-presales.github.io/demos/`).

## Règle : pages de démo / test de chatbot

Toute demande de création d'une page de démo ou de test pour un chat/chatbot doit être réalisée avec le skill `page-demo-chatbot` (`.claude/skills/page-demo-chatbot/SKILL.md`) et son template `assets/template_chatpage.html`. Ne jamais écrire une telle page de zéro.
